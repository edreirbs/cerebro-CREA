# inbox

Buzón crudo. **Aquí cae todo sin decidir dónde va.**

Capturar y clasificar son dos trabajos distintos, y mezclarlos hace que no se
capture. Esta carpeta existe para que capturar cueste cero.

Se vacía en cada compilada: el contenido se destila a la nota que corresponda y
el original se borra **solo cuando ya está citado** en esa nota.

No se versiona el contenido de esta carpeta, solo su existencia.
